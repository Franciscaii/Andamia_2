# Atajos de teclado

Mapa de combinaciones observado en el panel de atajos. Las descripciones son propias. Solo se probó Esc; el resto está leído del panel, no ejercitado.

El panel ofrece volver a los valores por defecto y permite asignar combinaciones a acciones que no traen una, así que los atajos son **personalizables**.

## Generales

| Acción | Combinación |
|---|---|
| Guardar | Ctrl+S |
| Sincronizar | `.` |
| Cancelar o cerrar | Esc |
| Deshacer / rehacer | Ctrl+Z / Ctrl+Shift+Z |
| Imprimir | Ctrl+P |
| Iniciar o pausar enfoque | Ctrl+Shift+P |
| Menú de comandos | Ctrl+K |
| Ver atajos | `?` |

## Tareas

| Acción | Combinación |
|---|---|
| Nueva tarea | Tab+N o N |
| Tarea debajo de la actual | Enter |
| Subtarea | Shift+Enter |
| Expandir o contraer subtareas | Tab+E |
| Vista de lista / tablero / cronograma | V y luego L / K / T |

## Prefijos de entrada rápida

| Dato | Prefijo |
|---|---|
| Fecha | `*` |
| Prioridad | `!` |
| Etiqueta | `#` |
| Lista | `~` o `^` |
| Asignar a miembro | `@` |

## Con el cursor sobre una tarea

| Acción | Combinación |
|---|---|
| Completar | Tab+M |
| Fijar | Tab+P |
| Borrar | Ctrl+Supr |
| Poner fecha | Tab+D |
| Quitar hora | Tab+0 |
| Hoy / mañana / próxima semana | Tab+1 / Tab+2 / Tab+3 |
| Prioridad | Alt+0, 1, 2 o 3 |

## Navegación

Todos empiezan con G, excepto la búsqueda.

| Destino | Combinación |
|---|---|
| Búsqueda | `/` |
| Ajustes | G, S |
| Todas | G, A |
| Hoy | G, T |
| Mañana | G, R |
| Próximos 7 días | G, N |
| Asignadas a mí | G, M |
| Bandeja | G, I |
| Completadas | G, C |
| Descartadas | G, W |
| Resumen | G, B |
| Papelera | G, G |

## Calendario

| Vista | Combinación |
|---|---|
| Día | D o 1 |
| Semana | W o 2 |
| Mes | M o 3 |
| Año | Y o 4 |
| Agenda | A o 5 |
| Volver a hoy | T |

## Comportamiento de Esc

Probado en el selector de fecha: la primera pulsación cierra el submenú abierto y la segunda cierra el selector. Ninguna guarda cambios.

## Decisión para Andamia

Usar combinaciones propias coherentes con estas categorías. Tab como prefijo choca con la navegación por teclado, así que hay que comprobar la accesibilidad antes de adoptarlo.
